# v2.2 · Windows x64 便携版 / Portable release

下载 [ForTheEmperor-v2.2-win-x64.zip](ForTheEmperor-v2.2-win-x64.zip)，完整解压后进入同名文件夹，双击 `ForTheEmperor.exe`。首次选择简体中文或 English，之后可在主界面更改。

Download the ZIP, extract it, open the enclosed folder and double-click `ForTheEmperor.exe`. Choose English or Simplified Chinese at first launch. The .NET desktop runtime and character artwork are embedded; no separate runtime installation is needed.

Requires Windows 10/11 x64. Use the execution demo first; it does not affect real files. The file command moves supported desktop files to the Windows Recycle Bin, with no permanent-delete fallback.

文件夹也可直接整体复制给别人。包含中英文使用说明、素材来源和运行时许可。`SHA256SUMS.txt` 提供 ZIP 和 EXE 的 SHA-256 校验值。

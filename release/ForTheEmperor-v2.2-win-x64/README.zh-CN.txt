FOR THE EMPEROR · 桌面战士 v2.2

1. 将整个压缩包解压到本地文件夹。
2. 打开 ForTheEmperor-v2.2-win-x64 文件夹，双击 ForTheEmperor.exe。
3. 首次启动选择简体中文或 English；后续可在指挥面板切换语言。

支持 Windows 10/11 x64。EXE 包含 .NET 桌面运行时和角色素材，
不需要另装 .NET、SDK 或手动复制 DLL。首次启动可能稍慢。

先点击“演练处决动画”，观看效果，不操作真实文件。
拖动角色可移动；单击互动；双击打开指挥面板；右键更换战团。

保持程序运行，并开启“启用文件右键处决”。
右键桌面上的单个普通文件，选择“以帝皇之名处决”。
Windows 11 请先点“显示更多选项”。
角色攻击命中后，文件才会移入 Windows 回收站，不会永久删除。
命中前可按 Ctrl+Alt+Esc 取消；回收成功后可从回收站恢复文件。
不支持文件夹、桌面子目录内的文件、网络文件或多选。

关闭指挥面板不会退出桌宠。请使用桌宠或系统托盘菜单中的
“退出并移除右键菜单”。
设置及本地日志保存在 %LOCALAPPDATA%\ForTheEmperor\。
日志可能包含执行过的文件名；向别人提交日志前请自行检查。

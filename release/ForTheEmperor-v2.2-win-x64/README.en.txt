FOR THE EMPEROR · Desktop Companion v2.2

1. Extract the entire ZIP to a local folder.
2. Open ForTheEmperor-v2.2-win-x64 and double-click ForTheEmperor.exe.
3. Choose English at first launch. Change it later using Language in the panel.

Requires Windows 10/11 x64. The executable includes the .NET desktop
runtime and character artwork. No separate .NET, SDK or DLL download is needed.
First launch may take longer to extract the embedded native runtime components.

Select Run execution demo first. This mode does not affect real files.
Drag the marine to move it, click to interact, double-click for controls,
or right-click to change chapters.

Keep the app running and enable the file execution command in the panel.
Right-click a regular file directly on your desktop, then select
Execute in the Emperor's name. On Windows 11, select Show more options first.
The file is moved to the Windows Recycle Bin only after the attack lands.
The app does not permanently delete files.
Press Ctrl+Alt+Esc before impact to cancel. After successful recycling,
use the Windows Recycle Bin to restore the file if needed.
Folders, desktop subfolders, network files and multiple selections are unsupported.

Closing the command panel leaves the companion running. To exit, choose
Exit and remove file command in the pet or system tray menu.
Preferences and local logs are stored in %LOCALAPPDATA%\ForTheEmperor\.
Logs may contain processed file names. Review them before sharing.
